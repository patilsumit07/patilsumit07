## 🚀 Quick Start

### 1. Fork this repository

Click **Fork** and create a copy under your GitHub account.

### 2. Enable GitHub Actions

Go to:

`Settings → Actions → General`

Make sure Actions are enabled.

### 3. Run the workflow

Go to:

`Actions → 🐍 Cyber Contribution Snake → Run workflow`

### 4. Add it to your profile

Copy this into your GitHub profile README:

```html
<picture>
  <source
    media="(prefers-color-scheme: dark)"
    srcset="https://raw.githubusercontent.com/YOUR_USERNAME/cyber-contribution-snake/output/cyber-snake-dark.svg">

  <source
```
